Learning Outcomes

  • Predict GC retention using boiling point, analyte polarity, and column polarity.
  • Select an appropriate GC column.
  • Evaluate oven temperature, temperature programming, and carrier-gas flow.
  • Evaluate chromatographic separation.
  • Use a mass spectrum associated with an individual GC peak to identify a compound.
